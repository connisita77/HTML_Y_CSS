# HTML_Y_CSS

Proyecto de HTML y CSS con el fin de usar todos los conocimientos previos aprendidos sobre el codigo y todas las funciones aprendidas,en el se podra observar desde selectores universales, etiquetas,parrafos,listas,etc.

## CONTENIDO Y FUNCIONES


Selectores en HTML y CSS

1.Crea un nuevo documento HTML desde cero con una estructura básica que incluya al menos un título (<h1>), una lista desordenada (<ul>) con elementos de menú y un área descriptiva con un id de "descripcion".

2.Utiliza selectores universales (``) para establecer una fuente común para todo el documento.
Aplica estilos a través de selectores de etiquetas (h1, a) para cambiar el fondo, color de texto y otros atributos de estos elementos.

3.Utiliza selectores de id (#titulo, #descripcion, #usuario) para aplicar bordes y espaciados específicos a los elementos identificados por estos identificadores.
Emplea selectores de clase (.parrafo, .parrafo1, .parrafo2) para agregar estilos adicionales como cursiva, subrayado y negrita a párrafos específicos.

4.Implementa selectores de atributos (input[type="text"], input[type="submit"]) para estilizar los elementos de formulario de manera diferenciada.

5.Experimenta con selectores de hijo (#menu > li > a) para modificar el estilo de los enlaces directos dentro de la lista de menú.
Explora el uso de selectores de prioridad (#saludo h1) y la propiedad !important para dar prioridad a ciertas reglas de estilo.
Añade nuevos elementos HTML según sea necesario para expandir la práctica de selectores y estilos.

Asegúrate de verificar que los estilos se apliquen correctamente y mantén el documento HTML organizado.
